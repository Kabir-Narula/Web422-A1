# WEB422 Assignment 1 — Listings API

Assignment 1 for **WEB422** at Seneca — Node/Express API for managing real-estate-style listings with MongoDB.

## Features

- CRUD operations for property listings
- Mongoose schemas and validation
- REST endpoints for listing data

## Stack

Node.js · Express · MongoDB · Mongoose

## Run locally

```bash
npm install
node server.js
```

Set `MONGODB_URI` in `.env`.
